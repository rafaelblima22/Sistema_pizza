📌 Sobre o projeto

O Sistema-Pizzaria é uma aplicação web desenvolvida com Django, com foco no gerenciamento de pizzas e na autenticação de usuários.

⚙️ Funcionalidades
🔐 Login: autenticação de usuários no sistema.
🍕 CRUD de pizzas: cadastro, consulta, edição e exclusão de pizzas.

🛠️ Tecnologias utilizadas
Python
Django
HTML
JavaScript
SQLite3

Instale as dependências:
pip install -r requirements.txt
